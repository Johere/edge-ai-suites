## LOCAL_PROMPT
## 任务:
分析这段短视频中单人居住老年护理卧室的可见活动，并输出结构化字段。
Start time: {st_tm}s
End time: {end_tm}s
## 观察顺序:
1. 房间内可见人物：先确认是否有住户（住户外观固定：单人居所常见长者），再确认是否同时存在身穿护理制服的第二人。
2. 人物位置与状态：所在区域（床上/床侧/房间中部/门口）、姿态（躺/坐/站/行走）、与床垫或床沿的关系。
3. 动作与状态变化：起坐、起身、行走、转身、回床、经过门口等。
4. 与物体/门/家具的交互证据（扶手椅、电视、门开启）。
## 事件判定契约:
- 事件 in_bed
  - 判定条件: 住户躺在床上，可见躯干在床垫上；不论清醒或闭眼。
  - 排除条件: 被窝下翻身、调姿、坐起抬头；床头灯亮起；床上坐起。
  - 固定严重程度: info。
- 事件 sit_up_in_bed
  - 判定条件: 住户从平躺变为坐姿，或坐在床沿且双脚着地（仍与床垫接触）。
  - 排除条件: 被窝下翻身或仅抬头；起身离开床垫站立。
  - 固定严重程度: info。
- 事件 out_of_bed
  - 判定条件: 住户双脚着地且人已离开床垫，处于站立或房间内走动状态。
  - 排除条件: 坐在床沿双脚着地仍计为 sit_up_in_bed；开床头灯或坐起喝水不计为离床。
  - 固定严重程度: info。
- 事件 in_room_activity
  - 判定条件: 住户起床后在房间内活动——行走、踱步、坐在扶手椅上、阅读、看电视等。
  - 排除条件: 护理人员在房间内走动属于 staff_* 事件，不是住户的 in_room_activity；纯被窝下翻身不计为 in_room_activity。
  - 固定严重程度: info。
- 事件 return_to_bed
  - 判定条件: 住户回到床上并躺下，可见躯干重新置于床垫且姿态由坐/站变为躺。
  - 排除条件: 仅坐回床沿未躺下。
  - 固定严重程度: info。
- 事件 restlessness
  - 判定条件: 片段内观察到至少两次"坐→站"或"站→坐"转换（每次必须达到直立站立，臀部离开座椅或床垫），或持续无目的踱步且无法安静下来。
  - 排除条件: 单次站立动作；因开灯、喝水、接物的单次起身；翻身调姿。
  - 固定严重程度: warn。
- 事件 night_out_of_room
  - 判定条件: 住户穿过门口离开房间，片段结束时房间内无人可见。
  - 排除条件: 开门未通过门洞；住户离开但仍有他人留在房间；开床头灯或坐起喝水。
  - 固定严重程度: warn。
- 事件 staff_enter
  - 判定条件: 身穿护理制服的第二人进入房间。
  - 排除条件: 第二人非护理制服（如家属、访客、维修）按不确定处理；住户本人移动不计。
  - 固定严重程度: info。
- 事件 staff_leave
  - 判定条件: 身穿护理制服的第二人离开房间。
  - 排除条件: 第二人非护理制服；住户本人离开按 out_of_bed 或 night_out_of_room 处理。
  - 固定严重程度: info。
- 事件 staff_visit
  - 判定条件: 同一片段内护理人员既进入又离开房间。
  - 排除条件: 仅进入或仅离开分别归入 staff_enter 或 staff_leave；非护理制服的第二人不计。
  - 固定严重程度: info。
- 事件 room_empty
  - 判定条件: 房间内完全看不到人。
  - 排除条件: 窗帘飘动、地板光斑移动、电视画面变化不构成事件，应按整体归为 room_empty 或 in_bed。
  - 固定严重程度: info。
- 事件 uncertain
  - 判定条件: 发生某种情况但无法确信地进行分类，例如关键姿态/主体被遮挡、光线不足、关键帧模糊。
  - 排除条件: 不要把"未观察到告警事件"当作不确定；当可视信息足够时应给出确定事件。
  - 固定严重程度: info。
## 不确定性策略:
- 当决定事件类别的关键证据（主体身份、姿态、是否离开床垫、是否穿过门口、是否穿护理制服）因遮挡/距离/光线不足/关键帧模糊而无法确认时，输出 uncertain。
- 室内环境噪声（窗帘飘动、地板光斑、电视画面变化）不构成不确定，应归为 room_empty 或 in_bed。
- 不要输出转换次数、步数或分钟数；只报告是否发生以及事件主体。
## 事件优先级:
- severity-first：critical > warn > info；本用例不输出 critical。
- 业务优先级（当无法同时满足时仅输出一个）：restlessness 与 night_out_of_room 优先于其他；staff_visit 优先于 staff_enter/staff_leave；return_to_bed 优先于 in_bed；sit_up_in_bed 优先于 out_of_bed；in_room_activity 优先于 out_of_bed；room_empty 与 uncertain 作为兜底。
- 同时满足多个事件时只输出一个 EVENT，次要发现只写入 DESC。
## 输出规则:
- 只输出 Final Schema 字段行，不要在字段前后输出正文。
- SEVERITY 只能是 info 或 warn；本用例禁止 critical。
- DESC 用 1-2 句中文描述支持判定的可见证据，不含计数值、步数或分钟数。
- 不要输出 JSON、YAML、数组、表格、代码块或分析过程。
- 不要输出计数（转换次数、步数、分钟数）；只输出事件主体。
## 输出格式:
SEVERITY: <与所选事件对应的 info 或 warn>
EVENT: <按优先级选出的一个事件名>
SUBJECT: <resident|staff|none>
DESC: <1-2句可见证据>
